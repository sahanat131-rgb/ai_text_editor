# Human vs AI-Generated Text Detector

A text classifier that predicts whether a short social-media style text was written by a human or generated by an AI, served as an API with an automated CI/CD pipeline.

*Live demo:* https://ai-text-editor-jvzw.onrender.com/docs
(Free hosting: the first request after idle time can take ~50 seconds to wake up.)

## Stack
- *Model:* TF-IDF + Logistic Regression (scikit-learn), tracked with MLflow
- *API:* FastAPI + Uvicorn
- *Packaging:* Docker
- *CI/CD:* GitHub Actions (pytest + Docker build on every push)
- *Hosting:* Render (auto-deploys from main)

## How it works
1. prepare_data.py builds a balanced human/AI dataset and splits it 70/15/15.
2. train.py trains the model and logs parameters and metrics to MLflow.
3. app.py serves the model with a /predict endpoint.
4. GitHub Actions runs the tests and builds the Docker image on each push.

## Try the API
bash
curl -X POST https://ai-text-editor-jvzw.onrender.com/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "your text here"}'

Returns {"prediction": "AI-generated" | "Human-written", "confidence": 0.0-1.0}.

## Run locally
bash
pip install -r requirements-api.txt
uvicorn app:app --reload

Or with Docker:
bash
docker build -t ai-text-detector .
docker run -p 8000:8000 ai-text-detector


## Known limitations
- Small dataset (62 AI samples, balanced with 62 human tweets), so confidence scores are low.
- Human examples are airline tweets, so the model may misjudge text from other domains.
- Next steps: more AI samples, more varied human text, drift monitoring and a retraining trigger.
